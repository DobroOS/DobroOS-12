## 🌟 Добро пожаловать в DobroOS!

**DobroOS 12** - это современная веб-операционная система, созданная с заботой о каждом пользователе. Работает прямо в браузере, без установки!

## ✨ Возможности

### 📱 Приложения
- 🧮 **Калькулятор** - простой и удобный
- 📝 **Блокнот** - для заметок
- 💻 **HTML Coder** - пиши и запускай HTML код прямо в системе
- ⚙️ **Настройки** - полная настройка системы
- ℹ️ **О системе** - информация о DobroOS

### 🎨 Персонализация
- 🎨 **Акцентный цвет** - выбери свой цвет (5 цветов + свой)
- 🖼️ **Фон рабочего стола** - загрузи свои обои
- 🪟 **Стекло (Glassmorphism)** - настрой размытие
- 📂 **Недавние фоны** - быстрое переключение

### 📐 Панель задач
- 🎯 **Плавающая** - по центру
- 📏 **Растянутая** - на всю ширину
- 🎨 **Цвет панели** - настрой под себя
- 🔆 **Прозрачность** - регулируй

### 🌐 Меню Пуск
- 🔲 **Сетка или список** - выбери стиль
- 📰 **DobroOS News** - новости системы
- 👤 **Профиль пользователя** - имя и аватар

### ⚙️ Дополнительные функции
- 📅 **Календарь** - всегда под рукой
- ☀️ **Яркость** - регулировка
- 🌍 **Языки** - Русский / English
- ⏰ **Формат времени** - 12/24 часа
- 🔄 **Обновления** - проверка в настройках
